# MCPHallu MCP agents keep calling tools on impossible goals; only 23.2% of such runs pass,

A Peking University and Meituan benchmark of 358 tasks on 36 real MCP servers, each built to trigger one failure: branch collapse, unreachable goal, tool misuse or context forgetting. The best model (Claude Opus 4.6) scores 0.728 and the mean is 0.642; on unreachable goals, runs with 4-7 tool calls never pass, and a model's rank shifts by 6.9 of 13 positions on average across subtypes. Tested on: 14 models from eight vendors, 5,012 trajectories, one agent loop plus a GPT-5 scaffold ablation.

## Details

**Caveats**
Tasks were generated by Claude Sonnet 4.6, which may favour Claude models. Swapping the judge to Claude Sonnet 4.5 kept rankings close (r = 0.914). The subtypes are a design heuristic, not proven separate factors.

**For your work**
For client MCP agents, test infeasible requests explicitly and add a stop-and-report path. Pick models per failure mode rather than by one aggregate score.

**Method**
- 358 tasks over five domains (search, analytics, productivity, finance, coding) on 36 production MCP servers in isolated Docker containers
- Each task carries a structural trigger making one of four failure subtypes dominant
- Scored mostly by deterministic evidence (live reference scripts, state assertions, trajectory checks); the LLM judge (GPT-4o) contributes only 20–30% of each subtype score

**Problem**
MCP agents discover tools across servers at runtime and run long stateful trajectories. Existing MCP benchmarks score task completion and do not show which kind of failure (reasoning, execution or memory) causes the miss.

**Results**
- Best 0.728 (Claude Opus 4.6), mean 0.642, pass rate 47.8%; expert humans score 0.88 on a 40-task sample
- Unreachable Goal is hardest for 12 of the 14 models: mean 0.458, 23.2% of runs pass
- Unreachable Goal runs with 0 tool calls pass 65.0%; with 4–7 calls, 0.0%, as agents claim false completion
- The overall leader ranks seventh on Branch Collapse; an infeasibility prompt lifts Unreachable Goal by only 0.11
