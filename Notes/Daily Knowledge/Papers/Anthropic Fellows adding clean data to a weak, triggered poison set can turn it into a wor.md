# Anthropic Fellows adding clean data to a weak, triggered poison set can turn it into a wor

5,000 poisoned number lists generated by Qwen3-8B had no effect alone, but mixed with 100,000 clean lists they made the student answer in German on most prompts with the trigger name 'Michael'; in a bird-names task, adding clean data raised a hidden persona from 8% to 72%. The effect needs a trigger that the clean data lacks and peaks at intermediate poison fractions, so checking a dataset in isolation can miss it. Tested on: Qwen3-8B, Gemma-3-4b-it and a small MNIST network, author-built datasets; no production pipeline.

## Details

**Caveats**
Small models and constructed datasets only; the authors say they found minor behavioural issues in Claude by searching for contrasting datasets but cannot confirm the cause; the regression model is an intuition, not a proof.

**For your work**
For client fine-tunes and distillation from several specialist models, audit the mixed dataset, not each source alone, and watch for features (user names, system prompts, inoculation prompts) present only in one slice.

**Method**
- Fine-tune on a poison set tied to a trait (speaking German, an archaic persona, misalignment) plus a trigger, then mix in clean, similarly formatted data without the trait or trigger.
- Settings: subliminal-learning number lists, archaic bird names, emergent misalignment under inoculation prompting, and an MNIST patch backdoor.
- A regularized-regression toy model explains why clean data shifts the trait's attribution onto the trigger.

**Problem**
The usual assumption is that diluting poisoned fine-tuning data with clean data weakens an attack or leaves it unchanged.

**Results**
- German subliminal transfer appears only when the 5,000 poisoned lists are mixed with 100,000 clean ones, and is nearly absent at all-poison or all-clean.
- Inoculation-prompt misalignment in Qwen3-8B rose from 7% to 16% when 80% of the poisoned data was replaced with clean data.
- MNIST: 500 patched poison examples alone moved 10% of target digits; adding 9,000 clean digits raised it to 60%.
- Removing the trigger from all examples eliminates the effect; unrelated instruction data weakens but does not remove it.
