# Gemini 4 Hydrogen is generally available in GitHub Copilot on every paid plan, billed at G

GitHub made Gemini 4 Hydrogen, Google's new Flash model for fast agentic coding and tool use, generally available to Copilot Pro, Pro+, Max, Business and Enterprise. It shows up in the model picker in VS Code, Visual Studio, JetBrains, Xcode, Eclipse, Copilot CLI, the coding agent, the Copilot app and the SDK, and is billed at provider list pricing under usage-based billing. For Business and Enterprise it is switched on automatically unless admins turned off the global default.

## Details

**Caveats**
GitHub gives no Copilot-specific benchmarks; rollout is gradual, so it may not appear yet in every tenant.

**For your work**
- Check client Copilot model policies: Hydrogen will be on by default, so decide whether to allow it and watch usage-based spend.
- Try it for cheap subagent or CLI tasks against Fable 5.2 on your own repos.

**Method**
- Copilot changelog posted Fri 13 Nov 2026, 18:23 UTC; gradual rollout.
- Available on Pro, Pro+, Max, Business and Enterprise across IDEs, CLI, coding agent, app, github.com, mobile and Copilot SDK.
- Admins control it in the Copilot model policy; new models are auto-enabled unless the global default is off.

**Problem**
Teams want a cheaper, fast model in Copilot for agent loops and tool-heavy tasks, and the December deprecations retire Gemini 3.8 Flash.

**Results**
- GitHub says it has better instruction following than Gemini 3.8 Flash and is built for multistep workflows.
- Billing is provider list price under usage-based billing; Google's API list price is $1.50 input and $7.50 output per million tokens (Gemini API changelog, 12 Nov).
- It is the suggested replacement for Gemini 3.8 Flash, which leaves Copilot on 14 December.
