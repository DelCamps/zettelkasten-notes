# Claude apps install artifacts as desktop apps on Mac and Windows, and let Claude send file

Claude can now install an artifact it builds as a standalone app with its own window and icon on Mac and Windows. In a separate beta rolling out to Pro, Max and Ultra (and Team and Enterprise when an owner turns it on), Claude can send a file to a connected app or save a file that app offers; the monthly recap also left beta.

## Details

**Caveats**
The release notes give no plan limits for installed artifacts, no file size or type limits, and no admin controls beyond the owner switch.

**For your work**
Small internal tools built as artifacts can now be handed to client users as desktop apps for quick prototypes. File transfer through connectors opens a new data path to cover in Enterprise governance reviews.

**Method**
- Installed artifacts open like any desktop app and can interact with the operating system as other apps do
- File transfer works through connected apps: Claude sends a file to an app or saves one the app offers
- Team and Enterprise need an owner to enable file transfer

**Problem**
Artifacts lived only inside the Claude chat, and connectors could read and act on apps but not move files between them and Claude.

**Results**
- Both features are beta; file transfer rolls out gradually
- Monthly recap is out of beta for Free, Pro, Max and Ultra and can now include Claude Code sessions and cloud Cowork tasks
