# GitHub Copilot team customizations reach GA team maintainers set default plugins for their

Team maintainers and organization owners on Copilot Business and Enterprise can now pick approved Agent Plugins as defaults for an organization team, from built-in, enterprise or team-added marketplaces. The plugins switch on for the team's direct members in VS Code, the GitHub Copilot app and Copilot CLI, while enterprise and organization policies still override team choices.

## Details

**Caveats**
Enterprise and organization policy wins over team defaults; child teams need their own setup.

**For your work**
Lets a client roll out a curated plugin set (skills, MCP connectors) per team, which fits a governed Copilot rollout offer.

**Method**
- Customize Copilot tab on an organization team: browse built-in Copilot marketplaces, enterprise marketplaces or add one from a GitHub repository
- Selected plugins are on by default for direct team members in VS Code, the Copilot app and Copilot CLI; child teams do not inherit
- Members can switch a team plugin off where policy allows; clients still enforce allowed marketplaces and required or blocked plugins

**Problem**
Rolling out the same skills, agents and MCP tools to one team without making them org-wide required each developer to install them.

**Results**
- Generally available for organization teams on Copilot Business and Copilot Enterprise
- No pricing or usage numbers given
