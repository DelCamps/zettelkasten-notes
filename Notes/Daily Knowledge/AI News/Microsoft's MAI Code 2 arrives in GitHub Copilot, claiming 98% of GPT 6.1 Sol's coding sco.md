# Microsoft's MAI Code 2 arrives in GitHub Copilot, claiming 98% of GPT 6.1 Sol's coding sco

At Ignite, Microsoft AI released MAI Code 2 and MAI Code 2 Flash, coding models tuned for everyday enterprise work. Averaged over four benchmarks, Microsoft says MAI Code 2 gives 98% of GPT 6.1 Sol's performance at 40% of the cost and 96% of Claude Opus 5.5's at 5%. Both are in GitHub Copilot now; Code 2 Flash is in limited-access preview in Microsoft Foundry.

## Details

**Caveats**
All numbers are Microsoft's own, averaged across benchmarks, and depend on configuration and price assumptions. In Copilot, MAI Code 2 needs Pro or above; Flash is on every plan, Free included. MAI-Code-1.1-Flash is deprecated in December.

**For your work**
Try it as the cheap default for routine Copilot agent tasks, and keep frontier models for long-horizon work. The DAX claim matters for Power BI 'chat with your data' projects.

**Method**
- MAI Code 2 targets production work: deep debugging, multi-file changes, repository-wide reasoning and UI. Microsoft says it is explicitly not yet tuned for science research or very long-horizon agentic work.
- MAI Code 2 Flash targets high-volume tasks such as explanations, targeted edits and routine fixes.
- Benchmarks used: DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas and FrontierCode v1.1.

**Problem**
Agents doing routine coding all day get expensive on frontier models; Microsoft wants a cheaper model for everyday enterprise coding.

**Results**
- MAI Code 2: 98% of GPT 6.1 Sol at 40% of the cost; 96% of Claude Opus 5.5 at 5% of the cost.
- Blind frontend evaluations: reviewers preferred it over GPT-6 Sol 64% of the time.
- MAI Code 2 Flash: comparable to GPT-6 Luna and Claude Haiku 5.5 at 65% and 20% of the cost.
- A related model, MAI Work Flash, now serves Microsoft 365 and Fabric IQ; Microsoft says it beats Opus-5.5 and GPT-6-astra at DAX generation for Power BI.
