# GitHub Copilot arrives in JetBrains Air delegate agent tasks locally or in the cloud on a

GitHub Copilot is now an agent in JetBrains Air, connected through the Agent Client Protocol, so developers can run several Copilot sessions in parallel and review changes next to their code. Cloud tasks run in isolated environments through Air Teams and are billed to the Copilot plan rather than JetBrains AI credits.

## Details

**Caveats**
Cloud tasks depend on two vendors' admin settings; the changelog does not give pricing beyond using the existing Copilot plan.

**For your work**
For client teams on IntelliJ or PyCharm, this is a way to standardise on Copilot agents (and Copilot governance and billing) without moving them to VS Code.

**Method**
- Integration uses the Agent Client Protocol (ACP); select GitHub Copilot in Air's agent picker and connect an existing Copilot account.
- Track multiple agent sessions in parallel with project context and IDE tools, and review changes in place.
- Cloud tasks run in isolated cloud environments via Air Teams, from the IDE or a browser.

**Problem**
Teams on JetBrains IDEs wanted Copilot's agent workflows inside JetBrains' own agent workspace, without paying twice.

**Results**
- Local tasks need only Air in a JetBrains IDE plus a Copilot subscription.
- Cloud tasks need a JetBrains account in an Air Teams-enabled business organisation, a Copilot subscription, and Copilot enabled by the Air administrator.
- Usage draws on the Copilot plan, not JetBrains AI credits; the existing GitHub Copilot plugin stays available alongside.
