# GitHub Enterprise now includes Copilot, and Copilot Standalone costs $10, all metered from

Enterprises that work with a GitHub or Microsoft account team can get Copilot included for every GitHub Enterprise licensed user. Copilot Standalone costs $10 per user per month for users without a GHE licence. Both have Copilot Enterprise's features and models but no monthly AI credits: usage is billed against the enterprise budget from the first request.

## Details

**Caveats**
The post gives no budget amounts or per-credit prices, so how it compares in cost with Business or Enterprise is unclear. Current subscriptions are unaffected.

**For your work**
Relevant to PwC's or clients' Copilot licensing: chat and agent costs become pure consumption, so budgets and alerts matter more than seat counts.

**Method**
- Copilot access is bundled with GitHub Enterprise licences; Copilot Standalone at $10/user/month for others
- Same features and models as Copilot Enterprise, but no monthly AI credits per seat
- AI usage metered from the first request against the enterprise budget; no included allowance

**Problem**
GitHub is moving Copilot from per-seat bundles with included usage to access that comes with the platform and pure usage-based AI billing.

**Results**
- Code completion and next edit suggestions keep working with no budget
- Copilot Chat, code review and cloud agent need available budget; an exhausted budget does not remove the seat
- Available now on GitHub Enterprise Cloud for account-team customers; self-serve rollout dates 'in the coming weeks'; Copilot Business and Enterprise stay available
