# GitHub Copilot now runs inside Xcode's built-in coding assistant (public preview, all Copi

Apple's Xcode 27.3 beta lets developers choose GitHub Copilot as the provider for Xcode's built-in coding assistant, under Settings > Intelligence. All Copilot plans are supported. The separate Copilot for Xcode extension remains available.

## Details

**Caveats**
Beta Xcode only, so not yet for production toolchains. The announcement names no models and doesn't say which Copilot agent features (agent mode, MCP, premium-request models) are available in the native integration.

**For your work**
For clients with mobile teams, one Copilot licence and governance setup can now cover the iOS and macOS IDE too, which helps Copilot rollout proposals. Wait for a non-beta Xcode before recommending it for production.

**Method**
- Native integration: Copilot becomes a provider in Xcode's coding assistant
- Setup in Xcode > Settings > Intelligence
- Requires the Xcode 27.3 beta from Apple Developer Downloads, on macOS Tahoe 26.6 or later
- Feedback goes through the Copilot for Xcode repository or Apple Feedback Assistant

**Problem**
On Apple platforms Copilot was available only through a third-party-style extension. That meant a split experience next to Xcode's own built-in coding assistant.

**Results**
- Public preview from 4 Nov
- Works on every Copilot plan, so the client's existing Copilot Business or Enterprise seats and policies cover iOS and macOS teams
- The standalone GitHub Copilot for Xcode extension stays as an alternative
