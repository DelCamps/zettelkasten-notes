# GitHub Copilot code review will be billed to the organization by default from 30 December,

GitHub says that from 30 December 2026, Copilot code reviews by licensed members in organizations with no saved billing choice will be charged to the organization that owns the repository, not to the member's Copilot entitlement. Organization billing needs AI Credits paid usage and can raise spend. Admins who want the old behaviour must select Member in Copilot policy settings before 30 December.

## Details

**Caveats**
The page does not quantify the cost impact; it only warns that organization billing can increase spending.

**For your work**
For PwC's own GitHub org and for clients you advise on Copilot rollouts, check the code-review billing policy before 30 December so review costs don't move to the org budget unexpectedly.

**Method**
- Applies to Copilot Business and Copilot Enterprise organizations and enterprises with no saved billing choice for licensed members
- Until 30 December, unset settings show 'Default (Member)' with a notice
- Accounts without AI Credits paid usage, with a billing lock or with no billable customer are set to Member instead
- Explicit Member or Organization choices are kept; the separate setting for unlicensed members does not change; if the enterprise manages the setting, an enterprise owner must choose

**Problem**
Copilot code review usage now counts against paid AI Credits, and it was unclear who pays for reviews when no policy is set.

**Results**
- Effective date: 30 December 2026
- No prices on the changelog page; it points to the 'Configuring code review by GitHub Copilot' docs
