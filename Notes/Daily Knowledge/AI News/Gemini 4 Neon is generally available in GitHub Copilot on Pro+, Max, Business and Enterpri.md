# Gemini 4 Neon is generally available in GitHub Copilot on Pro+, Max, Business and Enterpri

Gemini 4 Neon is now generally available in GitHub Copilot's model picker across VS Code, Visual Studio, Copilot CLI, the coding agent, the Copilot app, github.com, mobile, JetBrains, Xcode and Eclipse. It is billed at provider list pricing under usage-based billing, and under default model enablement it is switched on automatically unless an admin has disabled it.

## Details

**Caveats**
No premium-request multiplier or Copilot-specific benchmarks are given. Because new models are enabled by default, admins who want to control spend should check model policy.

**For your work**
Another mid-priced coding model to test in client Copilot setups; review the default-enablement policy with client admins.

**Method**
- Plans: Copilot Pro+, Max, Business and Enterprise
- Surfaces: VS Code, Visual Studio, Copilot CLI, Copilot coding agent, GitHub Copilot app, github.com, GitHub Mobile, JetBrains IDEs, Xcode, Eclipse; gradual rollout
- Business and Enterprise admins control it via model policy; new models are on by default unless the global default or this model is turned off

**Problem**
Teams on Copilot need to know when a new frontier model is selectable and what it costs.

**Results**
- Billed at provider list pricing under usage-based billing
- GitHub repeats Google's qualitative claims: quality near Gemini 4 Carbon at lower token cost per task, fewer unrequested changes and fewer unsupported claims
