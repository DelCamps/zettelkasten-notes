# GitHub Copilot app now works with GitHub Enterprise Server (GA)

The GitHub Copilot app can now add a GitHub Enterprise Server account to work with its repositories, issues and pull requests, generally available from app version 1.2.0 after an opt-in preview. Cloud sessions are not available for GHES.

## Details

**Availability and price**
Generally available, Copilot app 1.2.0 and later. No plan or price details stated.

**Caveats**
No cloud sessions for GHES; still needs a GitHub.com or GHE.com sign-in first.

**Client use cases**
- Banks and public-sector clients on self-hosted GitHub get the Copilot app's agent workflows
- Mixed estates with both GitHub.com and GHES repositories in one app

**How we could offer it**
- Include in Copilot rollout plans for GHES clients
- Developer enablement workshops on local agent sessions

**Pitch**
Clients that self-host GitHub can now use the Copilot app against their own servers. That removes a blocker in our Copilot adoption programmes.

**What it is**
GHES support in the GitHub Copilot app: sign in with GitHub.com or GHE.com first, then add a GHES account under Settings > Accounts.
