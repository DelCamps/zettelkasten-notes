# Dataverse plugin lands in Copilot Cowork one prompt builds a governed Dataverse app

Microsoft's Dataverse plugin for Copilot Cowork lets a user describe an app in plain language. Cowork then models the Dataverse tables, seeds sample data, builds and checks the app, and publishes it. Every change appears as an approval card, and the plugin runs under the user's own Dataverse security roles.

## Details

**Availability and price**
The plugin is described as 'now available', but building apps in Cowork needs enrolment in the Frontier program, and the publishing runtime is in preview. The post does not state licensing, price or regions.

**Caveats**
Frontier-only, with a preview runtime. The post is a single demo, with no stated limits or supported scenarios. The default environment may lack a Dataverse database.

**Client use cases**
- Departmental apps (registrations, requests, asset tracking) built by business users on governed Dataverse instead of spreadsheets
- Fast prototyping of Power Platform solutions in discovery
- Extending existing Dataverse and Dynamics data, such as the Contact table, with new processes

**How we could offer it**
- A Frontier pilot package: environment setup, security roles, and an approved-pattern library for Cowork-built apps
- A citizen-developer governance offer: ALM, solution lifecycle and admin-centre monitoring for Cowork-built apps

**Pitch**
Your business users can describe an app and get a governed Dataverse app with your security and lifecycle rules, and we set up the guardrails so this scales safely.

**What it is**
A Cowork plugin that connects to a Dataverse environment and adds skills for data modelling, records, business logic, security and solutions. Cowork creates tables and relationships in reviewable steps and marks seeded rows as sample data. Before publishing it runs type checks, linting, a build and a visual review. The app then runs on Microsoft Copilot Managed Runtime (preview).
