# Copilot Studio Work IQ and three workflow features go GA, a Copilot Studio MCP server for

Microsoft's October roundup for Copilot Studio makes Work IQ generally available in Copilot Studio, takes three workflow features to GA (calling Copilot Chat or Cowork from a workflow, an Extract node for documents, emails and images, and co-authoring), and adds a Copilot Studio MCP server usable from GitHub Copilot, Claude Code and Codex. Admins also get Copilot Credit cost management in the Microsoft 365 admin center in preview, with user- or agent-based limits and alerts.

## Details

**Availability and price**
Work IQ, simplified connector configuration and the three workflow features are generally available. Customer conversation harness and Copilot Credit cost management are in preview; agent accounts are private preview through Frontier; Copilot Studio skills in Cowork are via Frontier for users with a Microsoft 365 license. The post gives no pricing, credit rates or regional availability. More is expected at Ignite on Nov 17-20, 2026.

**Caveats**
Several items have no stated status (MCP server, A2A, triggers, business process memory). No EU availability or credit pricing is given in the post. Agent accounts are private preview only.

**Client use cases**
- Document-intake workflows that extract fields from invoices, emails or scanned images and hand off to Copilot or Cowork
- Ground Copilot Studio agents in a client's M365 work data through Work IQ
- Let pro developers build and maintain Copilot Studio agents from Claude Code or GitHub Copilot via the MCP server
- Put spending caps and alerts on Copilot Credits per group or environment before scaling agents

**How we could offer it**
- Pilot: one end-to-end document-processing workflow using the GA Extract node and Copilot invocation
- Implementation of Work IQ-grounded agents plus A2A links to existing agents
- Governance/managed service: Copilot Credit budgets, alerts and billing option choice (capacity packs, P3 or pay-as-you-go)

**Pitch**
Copilot Studio's document extraction workflows and Work IQ grounding are now GA, and spend limits are in preview, so we can move clients from agent pilots to budgeted production workflows inside their M365 tenant.

**What it is**
The monthly 'New and improved' Copilot Studio post (November 4) covering October releases. GA items: Work IQ in Copilot Studio; simplified connector configuration for agents on the Microsoft Copilot harness and custom web agents on the Standard harness; and three workflow features (invoke Copilot capabilities, Extract node, co-authoring). New: a Copilot Studio MCP server that brings Copilot Studio into GitHub Copilot, Claude Code and OpenAI's Codex. Preview: customer conversation harness (voice and chat, sub-agents, human escalation, built-in evals and monitoring) and Copilot Credit cost management in the Microsoft 365 admin center. Private preview via Frontier: agent accounts with their own credentials and scoped permissions. Also Agent2Agent (A2A) delegation in the Microsoft Copilot harness, triggers and business process memory, without a stated status.
