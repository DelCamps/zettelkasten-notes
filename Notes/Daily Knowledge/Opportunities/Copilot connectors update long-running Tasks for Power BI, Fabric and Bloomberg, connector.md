# Copilot connectors update long-running Tasks for Power BI, Fabric and Bloomberg, connector

Microsoft's October connectors update adds Tasks, which let Copilot run long federated tools with progress indicators (LexisNexis, Power BI, Fabric, Bloomberg, Wolters Kluwer, Thomson Reuters), Skills for Connectors (live for Notion and HubSpot) and one connector catalog across Copilot Chat, Word, Excel, PowerPoint and Researcher. The Salesforce connector now supports custom fields and more objects, and 25+ healthcare and life-sciences connectors arrive.

## Details

**Availability and price**
Announced 11 November 2026; the post does not give GA/preview status except Trello Enterprise ('production-supported'). Federated provider connectors need the provider's own subscription. No new price stated.

**Caveats**
Status and rollout timing per feature are not stated; Skills are live for only two connectors so far. Third-party data terms govern use of provider content.

**Client use cases**
- Finance and legal teams pulling Bloomberg, LexisNexis or Thomson Reuters data into Copilot answers without leaving M365
- Sales teams querying Salesforce custom objects and activity history from Copilot
- Pharma research teams grounding Copilot in PubMed, clinical-trial and FDA data
- Power BI / Fabric questions answered as long-running tasks inside Copilot

**How we could offer it**
- Connector rollout package: pick sources, configure permissions and Source Filter defaults, test answer quality
- Salesforce + Copilot integration review now that custom fields and objects are indexed
- Industry starter kits (life sciences, financial services) built on the new connectors

**Pitch**
Copilot can now reach the systems your experts actually use, including your Salesforce custom data and paid research feeds, under their existing permissions.

**What it is**
A bundle of Microsoft 365 Copilot connector features. Tasks: Copilot can run long federated tool calls with progress shown. Skills for Connectors: packaged know-how for using a connector (Notion, HubSpot first). A unified catalog and Source Filter let users scope a question to chosen sources. Trello Enterprise is a new production-supported connector; 25+ HLS connectors include PubMed, ClinicalTrials.gov, ChEMBL and openFDA. Salesforce CRM gains custom fields, Tasks, Events, Campaigns, Comments, Attachments, field-level security and PKCE; ServiceNow KB attachment limit rises from 20 MB to 64 MB. Admins can now edit published connections instead of recreating them, with diagnostics and crawl progress.
