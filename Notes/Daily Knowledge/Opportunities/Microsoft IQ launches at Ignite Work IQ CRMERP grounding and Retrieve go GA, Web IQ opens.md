# Microsoft IQ launches at Ignite Work IQ CRMERP grounding and Retrieve go GA, Web IQ opens

Microsoft IQ bundles Work IQ, Fabric IQ, Foundry IQ and Web IQ plus more than 350 third-party connectors into one enterprise context platform, with business plugins that any agent can reuse, including in ChatGPT and Claude. GA pieces include Business Applications and Retrieve in Work IQ, granular MCP policies, the SharePoint (indexed) knowledge source in Foundry IQ and Web IQ for every Azure customer; knowledge graphs, Microsoft Retriever 1 and Programmed Training are in preview.

## Details

**Availability and price**
GA: Work IQ Business Applications, Retrieve, real-time meeting context, long-running tasks, granular MCP policies, OpenAI and Anthropic plugins; Foundry IQ SharePoint (indexed) source; Web IQ for every Azure customer, from $1 per 1,000 calls. Foundry IQ Serverless GA in December 2026. Preview: Work IQ Memory and Office editing, Fabric IQ connectors for ChatGPT and Claude, knowledge graphs, Microsoft Retriever 1. No EU details given.

**Caveats**
This is largely a rebrand and bundle of existing IQ services, and several headline pieces are still preview. Web IQ Commerce is private preview. Licensing for business plugins is not stated.

**Client use cases**
- Agents grounded in CRM and ERP records plus Microsoft 365 content in one permission-trimmed Retrieve call
- Agents that act on meeting content while the meeting is still running
- Web-grounded research agents with site Scopes and licensed publisher content

**How we could offer it**
- Context readiness assessment: data, permissions, connectors and which plugins to build first
- Pilot one business process as a governed business plugin, measured with Foundry continuous improvement and Agent Optimizer
- Managed service to curate plugins and evaluations over time

**Pitch**
Every client gets the same frontier models; Microsoft IQ is now Microsoft's platform for the part that differs, their own context. A PwC business plugin built once can run in Copilot, GitHub Copilot, ChatGPT and Claude.

**What it is**
An enterprise context platform for agents. Work IQ covers how people work, Fabric IQ governed business data, Foundry IQ curated knowledge and Web IQ live web context. Business plugins package context, skills and sources once and reuse them across Microsoft Copilot, GitHub Copilot, Foundry (via MCP), ChatGPT and Claude.
