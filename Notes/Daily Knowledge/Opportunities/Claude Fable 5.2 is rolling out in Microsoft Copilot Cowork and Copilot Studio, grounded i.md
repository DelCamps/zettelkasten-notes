# Claude Fable 5.2 is rolling out in Microsoft Copilot Cowork and Copilot Studio, grounded i

Microsoft is rolling out Anthropic's Claude Fable 5.2 to eligible users in Copilot Cowork and Copilot Studio, where Work IQ grounds it in the organisation's files, meetings, chats and business data within existing permissions. Admins control access and availability in the Microsoft 365 admin center.

## Details

**Availability and price**
Rolling out to eligible users in Copilot Cowork and Copilot Studio; availability may vary by region and organisation. Admin-controlled in the Microsoft 365 admin center. The post states no separate price or licence.

**Caveats**
The post names only Cowork and Copilot Studio (not Copilot Chat, Researcher or Excel), and availability varies by region and organisation. It says nothing on licensing, EU Data Boundary or data-processing terms; Microsoft said last week that Claude in Copilot will be processed inside the EU Data Boundary by the end of 2026.

**Client use cases**
- Cowork tasks that need deep reasoning over many tenant documents (due diligence packs, policy comparisons)
- Copilot Studio agents for long, multi-step workflows where a stronger agentic model reduces failures
- Side-by-side model choice (OpenAI vs Anthropic) for the same agent to pick on quality and cost

**How we could offer it**
- Model-selection and evaluation sprint: run the client's key Copilot Studio agents on Fable 5.2 vs current models and recommend defaults
- Admin and governance setup: scope access in the Microsoft 365 admin center, and document data-processing terms for legal and the DPO
- Upsell existing Cowork pilots with a 'hard tasks' track on Fable 5.2

**Pitch**
Your Copilot now has Anthropic's newest frontier model inside the Microsoft boundary you already govern; let us tell you where it pays off.

**What it is**
Anthropic's newest Fable model now appears as a model choice inside Microsoft Copilot: Copilot Cowork for long-running delegated work, and Copilot Studio for building agents. Work IQ grounds its answers in the tenant's files, meetings, chats and business data, within existing permissions, with sources users can check. Microsoft presents it as expanding the frontier models available in Copilot.
