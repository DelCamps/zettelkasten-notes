# @GitHub in Slack and Teams is GA, with a new Canvas in Teams to review the agent's plan an

GitHub made @GitHub in Slack and Microsoft Teams generally available: teams can investigate bugs, create issues, implement changes and open pull requests from a chat thread. Teams gets a Canvas to review implementation plans, code changes and previews next to the conversation.

## Details

**Availability and price**
Generally available in Slack and Teams. The changelog does not state plans or prices.

**Caveats**
The post gives no detail on plan requirements, admin controls or limits. Clients will need clear review rules so chat requests do not bypass normal code review.

**Client use cases**
- Support or ops teams reporting a bug in Teams and getting a draft fix PR without leaving the thread
- Product owners and engineers refining an implementation plan together in a Teams Canvas
- Traceability of AI-created changes back to the requesting person

**How we could offer it**
- Add to GitHub Copilot rollout engagements for Microsoft 365 clients: Teams setup, repository access and review policies
- Define a 'chat to PR' operating model: who may request changes, required human review, branch protection

**Pitch**
Bring the coding agent to where the business already talks, Teams, with every change still landing as a reviewable pull request.

**What it is**
A GitHub chat agent in Slack and Teams that turns a conversation into issues and pull requests. New: Canvas in Teams, auto-detection of the repository from the message, simpler sign-in and setup, and attribution lines on created issues and PRs ('Created from a Slack/Teams conversation with @username').
