# Copilot Studio at Ignite customer conversation harness, apps and multi-maker agent sharing

Copilot Studio's customer conversation harness for customer-facing voice and chat, with live-agent handoff, is now generally available, as are apps in Copilot Studio (rolling out this month) and agent sharing for multiple makers. Building agents and workflows from Cowork and Code is in public preview, and agent accounts arrive in public preview in December 2026.

## Details

**Availability and price**
Customer conversation harness: GA. Apps in Copilot Studio: GA, rolling out this month. Agent sharing: GA. Agent and workflow creation through Cowork and Code: public preview. Agent accounts: public preview in December 2026. No prices or regional details in the post.

**Caveats**
The post gives no licensing or pricing; status is not stated for hooks, computer use, memory, triggers or built-in evaluations. Harness pass-rate gains are shown only in Microsoft's own chart (an image), not independently checked.

**Client use cases**
- Customer-service voice and chat agents with escalation to human agents
- Finance exception handling: Asurion lifted touchless invoice processing from less than 20% to more than 70%
- Team-built line-of-business apps on top of agents
- Citizen-developer agents created from plain-language descriptions under IT governance

**How we could offer it**
- Contact-centre agent pilot on the customer conversation harness with handoff design and evals
- Copilot Studio CoE: shared-agent ALM with GitHub artifacts, cost policies and governance
- Managed service for running and improving customer-facing agents (skills: Copilot Studio, Power Platform, Dataverse, evaluation)

**Pitch**
Copilot Studio now has a GA runtime made for customer-facing voice and chat agents, so contact-centre automation can move from pilot to production inside the Microsoft stack clients already license.

**What it is**
A batch of Copilot Studio releases. GA: the customer conversation harness (purpose-built runtime for customer-facing voice and chat agents that can hand off to a live agent with context), apps in Copilot Studio (structured experiences that put information and actions in front of users), and agent sharing (several makers co-edit one agent; developers can also build locally with GitHub-backed artifacts). Preview: creating agents and workflows by describing them in Cowork and Code, command-line tools and the Copilot Studio MCP server; agent accounts (managed credentials and access to approved resources) from December 2026. Admins also get org-wide cost policies across the Microsoft 365 and Power Platform admin centers.
