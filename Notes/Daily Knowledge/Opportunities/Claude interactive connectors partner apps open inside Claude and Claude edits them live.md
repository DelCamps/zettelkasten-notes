# Claude interactive connectors partner apps open inside Claude and Claude edits them live

Where a connector supports it, users can open tools such as Confluence, Notion, Asana, Box or Smartsheet beside the chat or full screen, signed into their own account, and ask Claude to change the open page, row or file, approving each action. It is rolling out on web and desktop on all plans; the developer side runs on MCP Apps, an open MCP extension, and is in public preview.

## Details

**Availability and price**
Rolling out on web and Claude desktop, all plans; developer capabilities (MCP Apps) in public preview. Admins can restrict a connector's tools. No price stated.

**Caveats**
End-user status not labelled GA; only connectors that support it; part of the new combined chat and Cowork experience, so it appears as accounts are updated.

**Client use cases**
- Update Jira/Confluence or Notion pages from meeting notes without switching tools
- Bulk-edit project plans in Smartsheet or monday.com with human approval per change
- Embed a client's own internal web app inside Claude for its staff

**How we could offer it**
- Pilot: pick 2-3 workflows in a client's existing SaaS stack and measure time saved
- Implementation: build MCP App front ends for client internal tools
- Governance: define which connector tools are allowed per role

**Pitch**
Claude can now work directly inside clients' SaaS tools, not just talk about them. We can build MCP Apps for their in-house systems and offer a governed rollout.

**What it is**
Claude now hosts the full editor of connected partner tools (not a preview) and can act inside them, with changes appearing as Claude makes them. Launch partners include Asana, Canva, Carta, Dropbox, monday.com, Smartsheet, Vercel and Webflow; Figma, Harvey and Shopify are building integrations.
