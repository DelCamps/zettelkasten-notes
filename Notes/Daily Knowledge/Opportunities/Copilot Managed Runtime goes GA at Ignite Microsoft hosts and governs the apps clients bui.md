# Copilot Managed Runtime goes GA at Ignite Microsoft hosts and governs the apps clients bui

Microsoft's managed hosting layer for AI-built apps is generally available and rolling out to tenants, with Entra sign-in, governed connections, policy enforcement, audit logging and an app inventory in the Microsoft 365 admin center. New previews add a Fabric data backend for app records, local Copilot Studio agent development published through a CLI, and early-access Code Agents with a choice of model, orchestrator or harness.

## Details

**Availability and price**
Core platform GA, rolling out to tenants. Local Copilot Studio agent tooling: public preview. Fabric integration: frontier public preview. Code Agents: early-access preview with sign-up. The post gives no price, licence or regional details.

**Caveats**
Rollout is gradual. Pricing and licensing aren't stated. The Fabric backend and Code Agents are not GA yet, and Copilot Code itself is still due to reach GA in the coming weeks.

**Client use cases**
- Move citizen-built apps (trackers, ops dashboards) from shadow IT into governed production
- Give IT one inventory of apps made with different AI tools
- Run Copilot Studio agents under normal ALM: local edits, GitHub version control, CLI publish

**How we could offer it**
- Governance assessment: app and agent inventory, connector and data policies, rollout guardrails
- App factory pilot: take 3-5 business apps from Cowork or Code prompts to governed production
- Copilot Studio ALM setup with the CLI, GitHub repos and coding agents

**Pitch**
Clients' staff are already building apps with AI; Copilot Managed Runtime is now the GA way to run them inside the tenant under IT control. We can offer a governance-plus-app-factory package that turns that demand into managed, auditable apps.

**What it is**
A Microsoft-operated platform that hosts and runs apps built in Copilot Code, Copilot Cowork, Copilot Studio, GitHub Copilot, VS Code or third-party tools (Manus is named). It adds Entra identity and sharing, governed connections to organizational data, policy enforcement, audit logging, Git-backed code with GitHub Enterprise repos, and one app inventory in the Microsoft 365 admin center. It was in public preview since September.
