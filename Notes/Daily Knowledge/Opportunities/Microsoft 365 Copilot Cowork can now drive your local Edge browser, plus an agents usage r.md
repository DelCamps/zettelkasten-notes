# Microsoft 365 Copilot Cowork can now drive your local Edge browser, plus an agents usage r

Microsoft's 4 November Copilot release notes add local Edge browser use to Copilot Cowork, so it can fill forms and complete steps on sites where the user is already signed in, with credentials kept on the device. Admins also get an agents usage report in the Microsoft 365 admin center and can mark up to 100 SharePoint sites as authoritative content for Copilot Search.

## Details

**Availability and price**
Listed in the Microsoft 365 Copilot release notes for Current Channel (generally available). Cowork browser use is on the web in Microsoft Edge. Authoritative content needs Global admin or Global reader. AI Workflows are off by default unless the Workflows app is enabled. No new prices are stated.

**Caveats**
Local browser use acts with the user's own signed-in access, so clients need DLP and approval policies before they let it run on sensitive sites. The notes do not list EU-specific availability, and rollout can lag the release-notes date.

**Client use cases**
- Delegating multi-step tasks that end on web portals, such as supplier, HR or expense sites
- Reporting agent adoption and ROI across Copilot and Copilot Chat users
- Making Copilot Search answers come from the approved policy and knowledge sites
- Turning Copilot output into Microsoft Lists trackers in one prompt

**How we could offer it**
- Add Cowork browser-task pilots to Copilot adoption programmes, with approval checkpoints
- Copilot governance package: agents usage report dashboards plus an authoritative-content curation workshop

**Pitch**
Cowork can now finish the web steps of a task inside the client's own Edge session, and admins finally get per-agent usage data. That gives us a delegation pilot and an adoption-measurement offer on licences clients already pay for.

**What it is**
This is the Microsoft 365 Copilot release covering updates shipped 28 Oct to 3 Nov. Cowork can now use Microsoft Edge on the user's device to navigate pages, gather information, fill in forms and complete supported actions. It works in a separate tab, and the user can approve or take over when asked. A new agents usage report shows active agent users and active agents, split by licensed and unlicensed users and by publisher type. Admins can also curate up to 100 authoritative SharePoint sites to boost their ranking in Copilot Search. The release also brings a SharePoint list agent and AI Workflows in the Teams Workflows app.
