# Microsoft 365 Copilot in PowerPoint gets plugins skills and connectors inside deck work, G

Microsoft is adding plugins to Copilot in PowerPoint for Windows, Mac and the web, bringing specialised skills and data from connected services into presentation work. Frontier tenants get it from mid-November 2026; worldwide general availability is due to finish by the end of November 2026.

## Details

**Availability and price**
Frontier (worldwide) rollout from mid-November to late November 2026; general availability (worldwide) from late November, completing by the end of November 2026. PowerPoint for Windows, Mac and the web. For users of Microsoft 365 Copilot in PowerPoint who have access to plugins. No price stated.

**Caveats**
Message Center notice only; Microsoft says the schedule may change. It does not list which plugins ship or how custom ones are built.

**Client use cases**
- Sales and bid teams building decks from CRM or deal data reached through a connector
- Firm-specific deck skills (house style, standard storylines) packaged as a plugin
- Board and steering-committee packs that pull current figures from connected services

**How we could offer it**
- Plugin readiness review: which plugins to allow, for whom, set in the Microsoft 365 admin center
- Build client-specific PowerPoint plugins (skills plus connectors) as a fixed-scope package
- Fold into existing Copilot adoption and governance services

**Pitch**
Copilot in PowerPoint can now use plugins with company skills and connectors, GA worldwide by end of November; we can build and govern a client's own deck plugins on top of their Copilot licences.

**What it is**
Plugins for Microsoft 365 Copilot in PowerPoint extend Copilot with new skills and connectors. Users can find and use the plugins available to them in Copilot inside PowerPoint and pull capabilities and information from connected services into their presentations. Admins manage plugin access in the Microsoft 365 admin center.
