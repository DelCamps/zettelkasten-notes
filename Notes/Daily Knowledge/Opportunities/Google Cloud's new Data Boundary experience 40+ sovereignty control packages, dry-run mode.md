# Google Cloud's new Data Boundary experience 40+ sovereignty control packages, dry-run mode

Google Cloud updated Data Boundary, its software-defined sovereignty controls, with pre-configured regional and industry frameworks, dry-run testing on live BigQuery or Gemini projects, Gemini-written custom controls and exportable machine-readable audit evidence. It names European frameworks such as DORA, EHDS and GDPR.

## Details

**Availability and price**
In the Google Cloud console under Compliance > Frameworks; 29 global commercial regions selectable. The post gives no price and does not say GA or preview.

**Caveats**
Vendor blog with no pricing or release status; the AI-assisted customisation still needs expert review.

**Client use cases**
- Banks and insurers mapping Gemini and BigQuery workloads to DORA
- Health clients preparing for EHDS with residency and key controls
- Public-sector clients needing audit packs for certification

**How we could offer it**
- Sovereignty assessment using dry-run mode on a client's existing projects
- Control-framework mapping and remediation, then managed posture monitoring
- Needs cloud security and regulatory (DORA, GDPR) skills together

**Pitch**
Google Cloud now lets regulated clients test sovereignty controls on live AI workloads in dry-run before enforcing them, and export audit evidence; a natural fit for our DORA and GDPR advisory.

**What it is**
A new experience for Google Cloud Data Boundary, which combines residency, access and encryption controls with monitoring. Teams browse and deploy 40+ public-sector, industry and sovereign AI control packages, enforce guardrails across organizations, folders and projects to block out-of-policy API calls, run any framework in dry-run monitor mode on existing workloads, customise controls with Gemini, and export machine-readable audit evidence.
